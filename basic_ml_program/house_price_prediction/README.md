# House Price Prediction

## About This Project
This is my first Machine Learning project.

It uses Linear Regression to predict house prices based on house size.

## Technology Used
- Python
- Scikit-learn
- Machine Learning
- Linear Regression

## How to Run

Install the required library:

pip install -r requirements.txt

Run the program:

python main.py

## What I Learned
- What Machine Learning is
- Features and labels
- Training a model using fit()
- Making predictions using predict()

## Disclaimer
This project uses a small artificial dataset for learning purposes. Predictions are not suitable for real property valuation.
